## FR-DGA-FIDELITY-001

[Source](https://github.com/stacks/stacks-project/blob/a04446e57ec1fbc252a871afcec7752fb2807b14/dga.tex#L6916)

Cette dernière propriété universelle quantifie sur A dans la source. La traduction avait réparé le nom de la cible en B. Les deux occurrences précédentes, également A dans la source, ne changent pas.

Source :
```tex
sending $\varphi$ to $(\varphi|_A, (s \mapsto \varphi(s)))$
is a bijection for every graded $R$-algebra $A$.
```
Avant :
```tex
qui envoie $\varphi$ sur $(\varphi|_A, (s \mapsto \varphi(s)))$ est
une bijection pour chaque $R$-algèbre graduée $B$.
```
Après :
```tex
qui envoie $\varphi$ sur $(\varphi|_A, (s \mapsto \varphi(s)))$ est
une bijection pour chaque $R$-algèbre graduée $A$.
```

## FR-COTANGENT-FIDELITY-001

[Source](https://github.com/stacks/stacks-project/blob/a04446e57ec1fbc252a871afcec7752fb2807b14/cotangent.tex#L2633)

Le deuxième module ambiant est nommé TrivRel dans le témoin, bien que Rel prime soit cohérent avec la construction. La correction de ce nom est conservée séparément.

Source :
```tex
of $Rel$, resp.\ $TrivRel$ generated by the elements
```
Avant :
```tex
le sous-module de $Rel$, resp.\
$Rel'$, engendré par les éléments
```
Après :
```tex
le sous-module de $Rel$, resp.\
$TrivRel$, engendré par les éléments
```

## FR-COTANGENT-FIDELITY-002

[Source](https://github.com/stacks/stacks-project/blob/a04446e57ec1fbc252a871afcec7752fb2807b14/cotangent.tex#L2907)

Le signe de zéro est conservé comme notation source de la flèche. Ce rétablissement typographique n’est pas un théorème mathématique corrigé : zéro et moins zéro ont la même valeur.

Source :
```tex
vertical maps $-1$ and $-0$ induce
```
Avant :
```tex
applications verticales $-1$ et $0$ induisent
```
Après :
```tex
applications verticales $-1$ et $-0$ induisent
```

## Lecture conservée — resolve / `lemma-issquare`

[Source](https://github.com/stacks/stacks-project/blob/a04446e57ec1fbc252a871afcec7752fb2807b14/resolve.tex#L3443)

Les mots anglais something et unit sont des descriptions de coefficients, non des variables algébriques dont il faudrait conserver les lettres. Le paragraphe complet du cas II et sa note ont été lus en parallèle. Un élément et une unité préservent exactement les deux coefficients indéterminés et le troisième inversible. Aucun changement du signe, de x_1, y_3 ou g.

```tex
y_3^2 - x_1((something)x_1 + (something)y_3 + (unit)g)
```
```tex
y_3^2 - x_1((\text{un élément})x_1 + (\text{un élément})y_3 + (\text{une unité})g)
```

## Lecture conservée — equiv / `lemma-sibling-faithful`

[Source](https://github.com/stacks/stacks-project/blob/a04446e57ec1fbc252a871afcec7752fb2807b14/equiv.tex#L2072)

Cinq exprime le même entier 5 dans le nom du lemme. Le renvoi demeure exactement le même et la preuve garde les deux usages covariant et contravariant. On ne réintroduit pas artificiellement des délimiteurs mathématiques dans un nom français.

```tex
$5$-lemma Homology, Lemma \ref{homology-lemma-five-lemma}
```
```tex
le lemme des cinq, Homologie, lemme \ref{homology-lemma-five-lemma}
```

## Limites

Les noms et la notation ont été comparés dans leurs passages, sans inventer une consultation initiale de canon. La comparaison des autres textes dans les formules, le reste de la prose et la terminologie générale ne sont pas certifiés. Les fichiers publics restent inchangés ; les modifications sont réversibles et liées à leurs témoins exacts.
